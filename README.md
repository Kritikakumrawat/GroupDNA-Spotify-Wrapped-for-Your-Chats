# 🧬 GroupDNA — Your WhatsApp Group Chat, Decoded

GroupDNA is a lightweight behavioral analytics engine that parses raw WhatsApp group chat exports to uncover deep structural communication patterns and automatically assign distinct personality archetypes to group members.

It is an web application that takes an exported WhatsApp group chat text file and transforms it into an interactive dashboard. Instead of reading through thousands of old messages, it uses machine learning to automatically analyze overall group dynamics, track conversation mood over time, and assign fun personality archetypes to every member.
